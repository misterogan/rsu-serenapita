# Bab 17. Menu dan tampilan

<p class="lead">Di sini Anda mengatur menu di bagian atas website: nama, urutan, dan tampil atau tidaknya. Anda juga bisa menyembunyikan atau menampilkan bagian-bagian halaman.</p>

## 17.1 Mengubah nama menu

1. Klik menu <b>Tampilan situs → Menu &amp; tampilan</b>.
2. Klik kolom nama menu yang ingin diganti, misalnya ubah "Dokter" menjadi "Dokter Kami".
3. Lihat bagian <b>Pratinjau header situs</b> di atas. Tampilannya langsung berubah sebagai contoh.
4. Klik <b>Simpan perubahan</b> di kanan atas.

<a id="menu-2" class="anchor"></a>

## 17.2 Mengubah urutan menu

1. Klik <b>panah atas</b> atau <b>panah bawah</b> di sisi kiri baris menu.
2. Ulangi sampai urutan sesuai keinginan. Pratinjau header ikut berubah.
3. Klik <b>Simpan perubahan</b>.

<a id="menu-3" class="anchor"></a>

## 17.3 Menyembunyikan atau menampilkan menu

1. Geser sakelar di ujung kanan baris menu. <b>Hijau</b> berarti tampil, <b>abu-abu</b> berarti disembunyikan.
2. Klik <b>Simpan perubahan</b>.

<div class="callout catatan"><b>Catatan</b><p>Menu <b>Beranda</b> selalu tampil dan tidak bisa disembunyikan. Menyembunyikan menu juga <b>menonaktifkan halamannya</b>: semua tombol dan tautan ke halaman itu ikut hilang dari website, termasuk tombol di slider, kotak info, footer, dan kartu dokter. Bila alamatnya diketik langsung, pengunjung melihat halaman "Halaman tidak ditemukan" dengan nomor kontak rumah sakit.</p></div>

<div class="callout tips"><b>Tips</b><p>Menu <b>Buat Janji</b> juga otomatis nonaktif bila tidak ada satu pun dokter yang tampil, misalnya semua sakelar Tampil di Profil dokter dimatikan. Chatbot pun akan mengarahkan pasien ke loket atau telepon.</p></div>

<div class="callout awas"><b>Hati-hati</b><p>Backoffice hanya mengatur <b>7 menu bawaan</b>: Beranda, Berita, Dokter, Jadwal, Layanan, Buat Janji, dan Kontak. Halaman atau menu baru, misalnya "Karier", belum bisa dibuat dari backoffice dan perlu dibuatkan oleh tim pengembang.</p></div>

<a id="menu-4" class="anchor"></a>

## 17.4 Bagian halaman yang bisa ditampilkan atau disembunyikan

| Kelompok | Bagian | Letaknya di website |
|---|---|---|
| Bagian beranda | Slider hero | Tulisan besar yang berganti di bagian paling atas beranda. |
|  | Kotak info | Tiga kotak berwarna: gawat darurat, jadwal dokter, dan jam pelayanan. |
|  | Berita terbaru | Kolom berita di beranda. |
|  | Daftar poliklinik | Daftar poli di samping berita. |
|  | Kotak buat janji | Kontak singkat untuk membuat janji di samping berita. |
| Elemen global | Bar informasi atas | Garis biru tua di paling atas yang berisi alamat dan nomor telepon. |
|  | Tombol chat | Tombol chat di pojok kanan bawah. Bila dimatikan, chatbot dan live chat tidak bisa dipakai pengunjung. |
|  | Loading perpindahan halaman | Logo berdenyut dan layar buram saat pengunjung pindah halaman. |
|  | Berita di footer | Tiga berita terakhir di bagian bawah halaman. |
|  | Tautan cepat di footer | Daftar tautan pintas di bagian bawah halaman. |
|  | Halaman karier | Tautan Karier di footer dan halaman lowongan kerja untuk pelamar. |
|  | Mode gelap otomatis | Bila aktif, website tampil gelap di HP atau komputer pengunjung yang memakai mode gelap. Bawaannya <b>mati</b>, sehingga website selalu tampil terang dan logo tetap jelas. |

Geser sakelarnya, lalu klik <b>Simpan perubahan</b>.

<div class="callout tips"><b>Tips</b><p>Bila <b>Mode gelap otomatis</b> diaktifkan, unggah juga <b>Logo untuk latar gelap</b> (versi putih) di menu Profil &amp; kontak. Header website akan memakai logo putih itu saat tampil gelap. Bila tidak ada, logo utama diberi kotak putih kecil agar tetap terlihat.</p></div>
