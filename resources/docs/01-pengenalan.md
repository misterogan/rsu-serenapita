# Bab 1. Mengenal backoffice

<p class="lead">Backoffice adalah "dapur" website. Di sinilah petugas menulis berita, membalas live chat, mengatur menu, dan mengelola akun petugas lain. Pengunjung website tidak bisa melihat halaman ini.</p>

<a id="pengenalan-1" class="anchor"></a>

## 1.1 Website dan backoffice

Ada dua bagian yang saling terhubung:

| Bagian | Alamat | Untuk siapa |
|---|---|---|
| <b>Website (situs publik)</b> | https://rsuserenapita.id | Pasien dan masyarakat umum. Berisi informasi rumah sakit, jadwal dokter, berita, formulir janji temu, dan chat. |
| <b>Backoffice</b> | https://rsuserenapita.id/admin/login | Petugas rumah sakit. Untuk mengubah isi website dan melayani pasien lewat live chat. |

## 1.2 Data dari SIMRS dan data yang Anda kelola

Sebagian data website diambil otomatis dari <b>SIMRS</b> (Sistem Informasi Manajemen Rumah Sakit), yaitu sistem yang dipakai bagian pendaftaran dan pelayanan. Data dari SIMRS <b>tidak bisa diubah di backoffice</b>, supaya tidak ada dua data berbeda untuk hal yang sama.

| Data | Diubah di | Keterangan |
|---|---|---|
| Nama, gelar, dan poli dokter | SIMRS | Muncul otomatis di backoffice dan website. |
| Jadwal praktik dan cuti dokter | SIMRS | Diperbarui berkala oleh sistem. |
| Janji temu dan statusnya | SIMRS | Pasien membuat janji di website, lalu janji langsung tercatat di SIMRS. |
| Foto dokter, warna avatar, profil singkat | Backoffice | Menu Profil dokter. |
| Deskripsi, urutan, dan tampil atau tidaknya poli | Backoffice | Menu Poliklinik. |
| Berita, slider, layanan, kotak info, menu, logo, alamat, nomor telepon, chatbot, live chat, pengguna | Backoffice | Semua menu lain. |

<a id="pengenalan-3" class="anchor"></a>

## 1.3 Yang dibutuhkan

- Komputer atau laptop. Layar lebar lebih nyaman, tetapi backoffice juga bisa dibuka dari HP.
- Browser <b>Google Chrome</b> atau <b>Microsoft Edge</b> versi terbaru.
- Koneksi internet. Di dalam jaringan rumah sakit, backoffice juga bisa dibuka lewat alamat <b>http://192.168.1.56:8000/admin/login</b>.
- Akun petugas berupa email dan kata sandi, yang dibuatkan oleh Administrator.

## 1.4 Istilah yang sering dipakai

| Istilah | Artinya |
|---|---|
| Klik | Menekan tombol kiri mouse satu kali pada tulisan atau tombol di layar. |
| Kolom isian | Kotak putih atau abu-abu tempat Anda mengetik, misalnya kolom Judul berita. |
| Tombol | Kotak berwarna yang bisa diklik, misalnya <b>Simpan</b> atau <b>+ Tambah berita</b>. |
| Sakelar | Tombol geser berbentuk lonjong. <b>Hijau</b> berarti aktif atau tampil, <b>abu-abu</b> berarti nonaktif atau disembunyikan. |
| Menu samping | Daftar menu berwarna biru tua di sisi kiri layar. |
| Ikon pensil | Membuka formulir untuk <b>mengubah</b> data. |
| Ikon tempat sampah | Untuk <b>menghapus</b> data. Selalu ada pertanyaan konfirmasi lebih dulu. |
| Panah atas dan bawah | Untuk mengubah <b>urutan</b> tampil. |
| Unggah (upload) | Mengirim file gambar dari komputer ke website. |
| Draf | Tulisan yang sudah disimpan tetapi belum tampil di website. |
| Terbit | Tulisan yang sudah tampil di website. |
| SIMRS | Sistem informasi rumah sakit yang menjadi sumber data dokter, jadwal, dan janji temu. |
| Live chat | Percakapan langsung antara pengunjung website dan petugas. |
| Chatbot | Asisten otomatis bernama Serena yang menjawab pertanyaan umum tanpa petugas. |
