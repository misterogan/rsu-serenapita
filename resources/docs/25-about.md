# Bab 25. Tentang kami

<p class="lead">Halaman Tentang Kami menampilkan profil rumah sakit: ringkasan, sejarah, visi dan misi, nilai, akreditasi, penghargaan, sambutan direktur, dan struktur organisasi.</p>

Halaman ini terbuka di alamat <b>rsuserenapita.id/about</b> dan muncul sebagai menu <b>Tentang Kami</b> di bagian atas website. Nama, urutan, dan tampil atau tidaknya menu diatur di <b>Menu &amp; tampilan</b>.

- Di komputer, arahkan mouse ke menu <b>Tentang Kami</b> untuk membuka submenu: Profil rumah sakit, Panduan pasien &amp; FAQ, Galeri, Pengaduan &amp; saran, dan Karier.
- Di HP, tekan tombol <b>Menu</b>, lalu tekan tanda panah di sebelah Tentang Kami.
- Submenu hanya ada di menu atas. Di footer, kelima halaman tetap tampil di kolom <b>Informasi</b>.

## 25.1 Mengisi halaman Tentang Kami

1. Klik menu <b>Informasi situs → Tentang kami</b>.
2. Isi bagian-bagian sesuai tabel di bawah. Bagian yang dikosongkan tidak akan ditampilkan.
3. Unggah foto rumah sakit, sertifikat akreditasi, foto direktur, dan bagan struktur organisasi bila ada.
4. Klik <b>Simpan</b>, lalu klik <b>Lihat halaman</b> untuk memeriksa hasilnya.

<figure><a href="/docs/img/about_admin.jpg" target="_blank"><img src="/docs/img/about_admin.jpg" width="1200" height="2184" alt="Gambar 25.2  Formulir Tentang Kami di backoffice." loading="lazy"></a><figcaption>Gambar 25.2  Formulir Tentang Kami di backoffice.</figcaption></figure>

| Kolom / tombol | Penjelasan | Aturan |
|---|---|---|
| <b>Ringkasan</b> | 2 sampai 3 kalimat yang tampil paling atas. | Wajib, maks. 600 karakter |
| <b>Sejarah</b> | Riwayat singkat rumah sakit. Pisahkan paragraf dengan satu baris kosong. | Maks. 6.000 karakter |
| <b>Visi</b> | Satu kalimat visi rumah sakit. | Maks. 600 karakter |
| <b>Misi</b> | Satu misi per baris. Tampil sebagai daftar bernomor. | Maks. 3.000 karakter |
| <b>Nilai atau moto</b> | Satu nilai per baris. Tulis "Nama nilai – penjelasan" supaya nama nilai tampil tebal, misalnya "Ramah – melayani dengan senyum". | Maks. 2.000 karakter |
| <b>Status akreditasi</b> | Misalnya "Terakreditasi Paripurna oleh KARS, 2024". Tampil sebagai label hijau. | Maks. 300 karakter |
| <b>Penghargaan</b> | Satu penghargaan per baris. | Maks. 3.000 karakter |
| <b>Nama, jabatan, dan kata sambutan direktur</b> | Bagian sambutan hanya tampil bila kata sambutan diisi. | Opsional |
| <b>Foto rumah sakit</b> | Foto gedung atau suasana, tampil lebar di atas halaman. | JPG, PNG, WebP, maks. 3 MB |
| <b>Sertifikat akreditasi</b> | Foto atau pindaian sertifikat. Pengunjung bisa mengkliknya untuk memperbesar. | Maks. 3 MB |
| <b>Foto direktur</b> | Tampil dalam lingkaran di samping kata sambutan. | Persegi, maks. 2 MB |
| <b>Struktur organisasi</b> | Gambar bagan organisasi. | Maks. 4 MB |
