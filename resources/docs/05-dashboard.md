# Bab 5. Dasbor

<p class="lead">Dasbor adalah halaman ringkasan yang biasanya pertama kali terbuka setelah masuk. Lewat halaman ini Anda bisa melihat kondisi pelayanan hari ini secara sekilas.</p>

<a id="dashboard-1" class="anchor"></a>

## 5.1 Isi halaman Dasbor

<figure><a href="/docs/img/dashboard_full.jpg" target="_blank"><img src="/docs/img/dashboard_full.jpg" width="1200" height="1005" alt="Gambar 5.1  Halaman Dasbor." loading="lazy"></a><figcaption>Gambar 5.1  Halaman Dasbor.</figcaption></figure>

| Bagian | Keterangan |
|---|---|
| Salam dan status SIMRS | Menampilkan tanggal hari ini dan kondisi koneksi ke SIMRS. Titik hijau berarti SIMRS terhubung, sedangkan titik merah berarti sinkron terakhir gagal. |
| Kartu merah: Janji temu hari ini | Jumlah janji temu hari ini dan jumlah pasien yang sudah hadir. Klik kartu untuk melihat daftarnya. |
| Kartu biru muda: Live chat menunggu | Jumlah pengunjung yang belum dibalas dan percakapan yang masih aktif. Klik kartu untuk membuka Live chat. |
| Kartu biru tua: Dokter aktif | Jumlah dokter berstatus Aktif di SIMRS. |
| Kartu biru: Berita terbit | Jumlah berita yang tampil di website dan jumlah draf yang belum terbit. |
| Tombol pintas | Tulis berita, Buka live chat, Sinkronkan SIMRS, dan Atur menu situs. Tombol hanya muncul bila Anda memiliki akses ke menunya. |
| Janji temu terdekat | Enam janji temu berikutnya yang belum selesai dan tidak batal. |
| Janji per poliklinik | Grafik jumlah janji temu per poli untuk 7 hari ke depan. |
| Cuti dokter | Dokter yang sedang atau akan cuti, berdasarkan data SIMRS. |
| Aktivitas terbaru | Enam perubahan terakhir oleh petugas. |
