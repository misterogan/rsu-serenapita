# Bab 14. Jadwal dan cuti dokter

<p class="lead">Halaman Jadwal dokter menampilkan jadwal praktik 7 hari ke depan. Menu Cuti dokter dipakai untuk mencatat cuti atau libur dokter dalam mode manual.</p>

<figure><a href="/docs/img/schedule.jpg" target="_blank"><img src="/docs/img/schedule.jpg" width="1200" height="906" alt="Gambar 14.1  Jadwal dokter 7 hari ke depan." loading="lazy"></a><figcaption>Gambar 14.1  Jadwal dokter 7 hari ke depan.</figcaption></figure>

- Setiap baris adalah satu dokter, dikelompokkan per poli.
- Kolom hari menampilkan jam praktik. Bila ada dua sesi dalam sehari, keduanya tampil bersusun. Tanda <b>—</b> berarti tidak praktik, dan tulisan kuning <b>Cuti</b> berarti dokter sedang cuti.
- Bagian <b>Cuti dan libur dokter</b> menampilkan periode cuti dengan status <b>Berlangsung</b>, <b>Akan datang</b>, atau <b>Selesai</b>.
- Dalam mode manual, tombol <b>Ubah jadwal dokter</b> membuka menu Profil dokter, dan tombol <b>+ Catat cuti</b> membuka formulir cuti. Dalam mode SIMRS, tombolnya adalah <b>Sinkronkan sekarang</b>.

## 14.1 Mencatat cuti dokter (mode manual)

<figure><a href="/docs/img/leaves.jpg" target="_blank"><img src="/docs/img/leaves.jpg" width="1200" height="906" alt="Gambar 14.2  Daftar cuti dokter." loading="lazy"></a><figcaption>Gambar 14.2  Daftar cuti dokter.</figcaption></figure>

1. Klik menu <b>Pelayanan medis → Cuti dokter</b>, lalu <b>+ Tambah cuti dokter</b>.
2. Pilih <b>Dokter</b>, isi <b>Mulai tanggal</b> dan <b>Sampai tanggal</b>. Untuk cuti satu hari, isi kedua tanggal dengan tanggal yang sama.
3. Isi <b>Keterangan</b>, misalnya Cuti tahunan atau Seminar.
4. Klik <b>Simpan</b>.

Selama periode cuti, jadwal dokter di website bertanda <b>Cuti</b>, dokter tidak bisa dipilih pada tanggal tersebut di formulir janji temu, dan chatbot memberi tahu pasien bahwa dokter sedang cuti.

<div class="callout catatan"><b>Catatan</b><p>Dalam mode SIMRS, cuti diambil otomatis dari SIMRS dan menu Cuti dokter hanya untuk dilihat.</p></div>
