# Bab 26. Tanya jawab dan mengatasi masalah

<p class="lead">Daftar masalah yang paling sering ditemui beserta cara mengatasinya.</p>

| Masalah | Cara mengatasi |
|---|---|
| <b>Saya sudah menyimpan, tetapi website belum berubah.</b>  | Buka halaman website lalu tekan <b>Ctrl + F5</b> untuk memuat ulang tanpa memakai cache. Di HP, tutup lalu buka lagi browser. Pastikan juga Anda sudah melihat pesan hijau setelah klik Simpan.  |
| <b>Berita baru tidak muncul di website.</b>  | Periksa Status, karena berita berstatus <b>Draf</b> tidak tampil. Periksa juga <b>Tanggal terbit</b>: kalau masih di masa depan, berita belum tampil. Terakhir, pastikan menu Berita tidak disembunyikan.  |
| <b>Berita tidak muncul di beranda.</b>  | Beranda hanya menampilkan 4 berita, dengan berita yang sakelar <b>Di beranda</b>-nya aktif didahulukan. Pastikan juga bagian <b>Berita terbaru</b> aktif di Menu &amp; tampilan.  |
| <b>Ada menu yang tidak terlihat di backoffice.</b>  | Peran Anda belum diberi akses ke menu tersebut. Minta Administrator mencentangnya di menu <b>Hak akses</b>.  |
| <b>Muncul halaman "403 Peran Anda tidak memiliki akses".</b>  | Sama seperti di atas. Anda membuka menu yang tidak diizinkan untuk peran Anda.  |
| <b>Data dokter salah, misalnya nama atau jadwal.</b>  | Data tersebut berasal dari SIMRS. Laporkan ke petugas SIMRS untuk diperbaiki, lalu klik <b>Sinkronkan sekarang</b> atau tunggu sinkron berikutnya.  |
| <b>Dokter tidak tampil di website.</b>  | Periksa sakelar <b>Tampil</b> di Profil dokter, status dokter di SIMRS (bukan Nonaktif), dan sakelar <b>Tampil</b> poli dokter tersebut di menu Poliklinik.  |
| <b>Gambar gagal diunggah.</b>  | Periksa format dan ukuran file sesuai [Bab 25](#gambar). Pesan merah di bawah kolom menjelaskan penyebabnya, misalnya file terlalu besar atau format tidak didukung.  |
| <b>Kategori tidak bisa dihapus.</b>  | Kategori masih dipakai berita. Pindahkan berita ke kategori lain lebih dulu.  |
| <b>Profil tidak bisa disimpan: "Centang minimal satu nomor untuk Kotak IGD".</b>  | Centang kolom <b>Kotak IGD</b> pada salah satu nomor telepon, biasanya nomor IGD.  |
| <b>Angka merah live chat tidak berkurang.</b>  | Angka menghitung chat berstatus Menunggu dan chat aktif yang belum dibaca. Buka percakapannya, lalu klik <b>Ambil percakapan</b> atau <b>Selesaikan</b>.  |
| <b>Pengunjung bilang balasan saya tidak sampai.</b>  | Pastikan percakapan tidak berstatus <b>Selesai</b>. Bila sudah selesai, klik <b>Buka lagi</b>. Minta pengunjung tetap membuka halaman chat, karena pesan baru muncul dalam beberapa detik.  |
| <b>Chatbot menjawab "Maaf, saya belum memahami".</b>  | Tambahkan entri FAQ dengan kata kunci dari pertanyaan tersebut ([Bab 18](#chatbot)), lalu uji di panel uji coba.  |
| <b>Janji temu berstatus "Gagal" di kolom Pengiriman.</b>  | Klik <b>Kirim ulang</b>. Bila masih gagal, hubungi tim IT dan konfirmasi ke pasien lewat telepon.  |
| <b>Saya lupa kata sandi.</b>  | Hubungi Administrator untuk dibuatkan kata sandi baru ([Bab 21](#users)).  |
| <b>Website atau backoffice tidak bisa dibuka sama sekali.</b>  | Periksa koneksi internet Anda. Bila internet normal tetapi halaman tetap tidak terbuka, hubungi tim IT, karena server atau koneksinya kemungkinan bermasalah.  |

## 26.1 Kontak bantuan

Bila masalah belum teratasi, hubungi tim pengelola website. Sertakan informasi berikut supaya cepat ditangani:

- Nama menu yang sedang dibuka.
- Langkah yang dilakukan sebelum masalah muncul.
- Tangkapan layar yang memperlihatkan pesan error. Tekan <b>Windows + Shift + S</b> untuk mengambil tangkapan layar.
- Waktu kejadian.
